# Real Portrait Mode for Camen — v1.15.0

**Approach (recommended path, per architecture comparison):** stay on expo-camera + the jpeg-js develop pipeline. Two small native additions make it real: (1) a patch-package fix to expo-camera for true tap-to-focus with AF/AE lock, (2) a thin local Expo module wrapping Google ML Kit selfie segmentation for the person mask. Depth blur runs in the existing develop pipeline (like Night mode — no live preview, honest PORTRAIT f/x label). All v1.9–v1.14 behavior stays intact.

## What ships
- **Tap-to-focus + focus lock**: tap anywhere → brass focus ring, AF+AE meters at that point and LOCKS (no auto-cancel); tap elsewhere to re-focus, tap the ring to unlock. Works in photo and video.
- **Depth bokeh at capture**: ML Kit person mask → feathered edges → 2-band background blur (near bg lightly blurred, far bg heavily blurred) → bokeh highlight glow → optional background tone shift.
- **APERTURE chip + f-stop ruler** (f/1.4–f/16) on the dashboard; strength carried in `develop` so presets + MY presets + ADJUST panel all carry it (v1.13 design boundary preserved).
- **Portrait preset upgrades**: Nature/Studio/Contour gain bokeh/glow/skin values + new **Stage Light** sub (darkened bg stage look).
- **Skin smoothing** (`skinSmooth` develop option) — subtle, skin-zone-aware, reuses applyGrade's warm-skin heuristic.

## Native work
1. **patch-package on expo-camera 57.0.5** (`patches/expo-camera+57.0.5.patch`, devDep + `postinstall` script):
   - `ExpoCameraView.kt`: add `focusPointX/Y` (normalized, default 0.5) + `focusKey` (Int, 0 = continuous); rewrite `startFocusMetering()` (currently hardcodes `createPoint(1f, 1f)`) to meter at the point with `FLAG_AF or FLAG_AE` + `.disableAutoCancel()`; `focusKey > 0` retriggers, `focusKey == 0` calls `cancelFocusAndMetering()`.
   - `CameraViewModule.kt`: register the 3 Props; patch `Camera.types.d.ts` for TS.
2. **Local Expo module `modules/camen-vision/`**: `segmentSelfie(uri, rawSizeMask) → {width, height, mask: FloatArray}` — BitmapFactory capped to ≤1024px long edge → `com.google.mlkit:segmentation-selfie:16.0.0-beta6` SINGLE_IMAGE_MODE. JS wrapper guards for absence (graceful no-blur fallback). Requires native rebuild (`expo run:android`).

## Pipeline work
3. **`src/features/portraitDepth.ts`** (new): mask fetch, feathering (blur the mask), quarter-res background blur bands (separable box ≈ Gaussian, reusing boxBlurU8), highlight-threshold glow layer, composite loop at full res with bilinear mask sampling. Core math exported as pure functions → Node test harness (existing gradePhoto practice). Own watchdog (race pattern), runs after develop, before webp.
4. **`useCamera.ts`**: focus state + `focusAt(x,y)/clearFocus()` on the hook; `focusPointX/Y/Key` passed to CameraView; clear on facing switch. `processCapture` gains the portrait step; AEB variants share one segmentation (mask cache per capture, geometry identical); failure → save unblurred + rlog (same policy as develop fallback).
5. **`gradePhoto.ts`**: `skinSmooth` pass inside applyGrade's skin zone; DevelopOptions += `bokeh`, `bokehGlow`, `bgTone`, `skinSmooth` (flows into presets/MY/DevelopPanel automatically).

## UI work (CameraScreen.tsx)

Replace `onTouchStart` double-tap hack with gesture-handler `Gesture.Exclusive(doubleTap→flip, tap→wake+focusAt)` (gives coordinates); `FocusRing` component (animated, brass when locked, tap-to-unlock); "AF·AE LOCK" FadeLabel; APERTURE chip (appears when `develop.bokeh > 0`) + f-stop `Ruler` (f/16…f/1.4 → strength mapping); "PORTRAIT f/x" FadeLabel like NIGHT MODE's.
